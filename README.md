# Pro Skill Packs

*Tested Agent Skills for the work you do every week.*

We build **Agent Skills for Shopify store owners**. Each skill does one store chore from start to finish and gives you something you can paste or import into Shopify without editing. Every skill is tested on real public Shopify stores before release.

## Free skills: [shopify-store-skills](https://github.com/proskillpacks/shopify-store-skills)

| Skill | What it does |
|---|---|
| shopify-alt-text-writer | Writes alt text for every product image, looking at each photo, and gives you a Shopify import CSV |
| shopify-policy-checker | Audits your refund, shipping, privacy and terms policies for gaps and contradictions, with fixes you can paste |
| product-title-cleaner | Puts every title in your catalog into one consistent pattern, as an import CSV |
| review-reply-drafter | Drafts a reply for each review, and flags the ones that need you personally |

Install in Claude Code:
    /plugin marketplace add proskillpacks/shopify-store-skills

Or with any SKILL.md agent:
    npx skills add proskillpacks/shopify-store-skills
